# E-commerce Sales & Profitability Dashboard | Power BI, SQL and Excel

I built this portfolio project with fictional e-commerce data to show how a retailer can reconcile order records and see which products, regions, and channels contribute to sales and gross profit.

**Business problem.** Pending and refunded orders were included in order volume, so the report needed a separate definition for completed-order revenue and profitability.

**My approach.** I used Excel 2021 to check and prepare 120 order records, MySQL to reconcile totals and compare segments, and DAX to build five financial KPIs in Power BI Desktop. I used Codex to assist with project file editing and documentation.

**Deliverables.** A formula-driven Excel workbook, reusable SQL queries and DAX measures, a Power BI dashboard with four interactive slicers, and a business insights summary.

**Results.** The five dashboard KPIs reconciled to 120 orders, BDT 1,459,250 in completed revenue, BDT 1,033,520 in COGS, BDT 425,730 in gross profit, and a 29.17% margin. The analysis surfaced monitor revenue concentration and showed how channel rankings differ when measured by gross profit versus margin.

**Skills and keywords.** Power BI, MySQL, SQL, Microsoft Excel, DAX, dashboard design, e-commerce analytics, data cleaning, financial reporting, KPI reconciliation.

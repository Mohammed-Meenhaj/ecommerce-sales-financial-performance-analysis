# Capture the Power BI dashboard

Use the original, verified Power BI Desktop project for the public screenshot.

1. Open **Financial Overview**. Clear all four slicers and any chart selections. Confirm all five cards agree with the [README](../README.md).
2. Maximize Power BI Desktop. Collapse the Filters, Data, and Visualizations panes as needed. Use **Fit to page** and make sure all cards and charts are legible.
3. Press **Win + Shift + S** and capture only the dashboard canvas. Keep the page title, KPI cards, slicers, and charts in frame. Leave out the ribbon, Windows taskbar, sign-in details, file paths, and any data source dialogs.
4. Save the capture as `financial_overview.png` in this folder. Use a high-resolution display if available, and review the PNG at full size before sharing.
5. Keep the image link in the README Dashboard preview section when replacing the capture.

   ```markdown
   ![Financial Overview in Power BI with five KPI cards, four charts, and four slicers](screenshots/financial_overview.png)
   ```

Use the same PNG for the Upwork portfolio after reviewing the crop in the upload preview.
